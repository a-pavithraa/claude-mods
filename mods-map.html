hindsightstops repeat snags
  • any tool call
  • a turn ends
  • Snag detectors: searching, repeat failures, huge output, slow or refused calls local
  • Same snag in a second session → Claude drafts one fix
  • Row above the prompt with the fix
  • /hindsight list
Saves the fix (for example a CLAUDE.md line) only when you press Save

Disables or removes one with claude plugin / claude mcp, after you confirm
